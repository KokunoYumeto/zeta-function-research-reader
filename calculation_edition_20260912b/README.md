## What is established here

The sources give exact finite-stage maps and matrix identities, complete
written derivations and separately identified numerical checks. The merged
boundary formalizations include five preserved modules with 38 selected
axiom checks and six integration modules with 68 selected checks, verified
under the pinned Lean/Mathlib toolchain. These formal checks cover their stated
algebraic structures, not all analytic theta estimates. The uniform
arithmetic-weight estimate motivating the programme remains unfinished.

See the [attempts and motivations](../CURRENT_RESEARCH.md#what-was-tried-why-and-what-it-produced)
and [formal integration note](../workbenches/tau-boundary-layer-integration/MATHEMATICS.md).
Human-source citations and the existing rights statements remain in each
work. Private transcripts and reference-library files are not included.
