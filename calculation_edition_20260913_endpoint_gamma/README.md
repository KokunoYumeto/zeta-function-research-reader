This edition computes norms and quotient volumes in the original theta-function
source. Its exact degree-window product keeps the phase and every interior
contraction. For an off-line quartet, the four-volume logarithm
`B_k=log(V_(q_k-1)V_(q_k)/(V_(2q_k-1)V_(2q_k)))` satisfies
`liminf B_k/(q_k log k) >= 4`. The opposing arithmetic upper estimate remains
unproved; no RH conclusion follows.

The main PDF contains the full endpoint, balanced-window, exact-product,
four-volume and corrected confluent-transfer arguments. The separate Gamma
companion preserves its own complete cumulative proof sequence. Written proofs,
finite regressions, interval enclosures and strict Lean results retain their
documented scopes; this mirror does not add a Lean execution or theorem claim.
