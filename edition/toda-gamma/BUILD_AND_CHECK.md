# Build and verification scope

Build the integrated reader by running `pdflatex -interaction=nonstopmode
-halt-on-error -file-line-error -recorder main.tex` three times in a working copy
with a suitable TeX installation. The archived dependency inventory binds every
input to the reviewed candidate. A reproducible typesetting invocation is not
a claim that another installation reproduces the identical PDF metadata.

The Gamma delivery includes its original Python/SymPy checker and historical
results. The independent Gamma checker and normal/optimized results are in
`reviews/gamma/`; the independent original-S-coordinate Toda fixtures and their
results are in `reviews/toda/`. Do not run checkers against frozen evidence files:
make a scratch copy, respect their output arguments and retain the original
receipts. No checker was executed by this packaging operation.

The delivered Gamma suite passed 17 methods in each mode. One explicit sentinel
was rejected in each mode. The independent Gamma fixtures passed 15 explicit
equalities and rejected six altered formulas per mode. The prior Toda source
suite and independent checks retain their original review scope. These are
finite fixtures, not actual nonempty zeta-packet certificates, growing-degree
control, a new interval run or a new local Lean theorem.

The frozen H package carries its own complete source/production evidence and
portable-replay records. The coordinating intake rechecked every packaged byte,
the stored terminal results, and saved rational enclosure endpoints. It did not
claim fresh execution of the full numerical workflow or a new all-page visual
review of that already-reviewed companion.
