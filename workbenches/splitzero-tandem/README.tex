This workbench contains the Split-Zero programme's complete source
papers, cumulative manuscripts, supporting proofs, figures and
calculation records. Its purpose is to connect support-preserving
coefficient geometry and arithmetic theta cohomology to quantitative
information about the Riemann zeta function's spectrum.

The coefficient construction retains the internal zero of a ring and a
separate symbol for absence. The analytic source is the theta complex
\texttt{{[}V\ →\ B{]}}: the specified theta map \texttt{Θ} gives the
quotient \texttt{B/ΘV}, and scaling acts by \texttt{D\ =\ −x∂x}. The
original integer-dilation operator has Mellin multiplier \texttt{ζ(s)}.
For the particular differential Gaussian source used in the analytic
papers, the full Mellin formula is \texttt{s(s−1)π\^{}(−s/2)Γ(s/2)ζ(s)},
also written \texttt{2ξ(s)} in earlier editions. That notation is not a
replacement for the original ζ: both endpoint terms, every Gamma and pi
factor, trivial zero, pole, exceptional local module and derivative
contribution remain in the
\href{https://github.com/KokunoYumeto/zeta-function-research-reader/blob/acd7016b8232a56f31ae3e69fb800571e8789080/workbenches/splitzero-tandem/continuations/20260923-retained-source-readers/original-zeta-full-boundary/independent/ORIGINAL_ZETA_THETA_CORRECTION.tex}{exact
source and return maps}. The chosen classical scalar kernel is an input
to this construction; deriving it from the entire absolute base was not
established. Finite packets retain all zero orders, source relations and
the specified original quotient metrics. Earlier estimates keep their
stated scope until their own full-factor reconstruction has been
completed.
