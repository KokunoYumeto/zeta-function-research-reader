# Original theta moments: complete finite Hankel certification

Start with `Tau_Theta_Hankel_Complete_Proofs.pdf`, the complete 47-page
reader. It combines the five-page TC note with 42 pages containing all nine
supporting proof bodies, including the original workbench and independent
reviews. `README.md` gives the source layout and reproduction commands.

The reported finite result concerns the original 16-by-16 matrices H15 and
its first shift for the unchanged function F(z squared) = 2 xi(1/2 + iz).
The certificate retains the 33 even moments M0, M2, ..., M64, the original
theta integral and its mass, the signed summands, and both factors of two.
It uses first omitted index 20, cutoff length 4, and 1024-bit ball arithmetic.
The supplied independent integer-interval replay uses denominator 2^4096
and checks 1,400 endpoint pairs; all 32 pivots and 32 leading determinants
have positive lower endpoints. These are the owner's certified results,
not a new execution by this distribution intake. No all-dimension,
infinite-dimensional, uniform-rate, or Riemann-hypothesis conclusion is
claimed.

Every file in the owner's sealed source archive is retained byte-for-byte:
all mathematics, exact test sources, saved inputs and results, original
proof bodies, layout conversions, and QA evidence. The distributed PDF is
also byte-identical to the owner's accepted 47-page PDF. This intake did
not re-evaluate the integrals, replay the mathematics, run Lean, or rebuild
the PDF. Its checks concern full-byte identity, complete inventory, PDF
structure and public safety.

is regenerated when the relevant Python module runs. Nothing was removed
from the sealed archive. The private owner seal, machine-specific paths,
local work folders, and intake scripts are not distributed. No external

certification. This distribution is prepared locally; it does not imply a
