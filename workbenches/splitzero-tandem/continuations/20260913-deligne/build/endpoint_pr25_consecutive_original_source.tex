\subsubsection{1. Exact consecutive product}\label{endpoint-pr25_consecutive_original--exact-consecutive-product}

For N\textgreater=q the existing identity is

\begin{verbatim}

\end{verbatim}

\begin{verbatim}

\end{verbatim}

\begin{verbatim}
