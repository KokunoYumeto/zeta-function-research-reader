\textbf{The attached four-endpoint criterion can be sharpened using its own exact radius identity.} The improvement comes from multiplying the consecutive-step identities \emph{before} discarding their imbalance terms. This preserves the fact that each interior volume contraction occurs in two adjacent control estimates.

The resulting four-endpoint bound is never weaker than the attachment's bound. It also has a simpler corollary:

\[
\boxed{
\min_{0\le j<r}\epsilon_{h,k,n+j}
\le
\left(
\frac{\omega_{n+r}V_n}
{\omega_nV_{n+r}}
\right)^{1/(2r)}.
}
\tag{1}
\]

This corollary uses only two quotient volumes and two monic norms. It is useful for controlling large contractions, although it need not outperform the original bound when the contractions are small.

These are deductions below from the supplied exact-radius, positivity, and monotonicity hypotheses---not an assertion that the remaining arithmetic endpoint estimates have been established. The attachment itself distinguishes that analytic obligation from the existing finite formalizations.

\subsubsection{1. An exact product identity for a whole degree window}\label{endpoint-user_product_original--an-exact-product-identity-for-a-whole-degree-window}

Fix the original packet \(h\), tensor degree \(k\), and cyclic dimension \(q\ge1\). Work at the original observation \(\theta=0\), or at a fixed admissible tilt for which the supplied identities hold. Suppress \(h,k,\theta\) from the notation.

Retain

\[
V_N=\det G_N>0,\qquad
\omega_N>0,\qquad
\delta_N=\frac{V_N}{V_{N-1}}\in(0,1],
\]

and write

\[
\phi_N=\sigma-\partial_\theta\log V_N
\]

for the original phase. The source identity is

\[
\boxed{
\epsilon_N^2+\phi_N^2
=
\frac{\omega_{N+1}}{\omega_N}
(1-\delta_N)(\delta_{N+1}^{-1}-1),
\qquad N\ge q.
}
\tag{2}
\]

The phase is therefore retained on the left, not set to zero.

Take a consecutive window

\[
N=n,\ldots,n+r-1,\qquad n\ge q,\quad r\ge1,
\]

and define

\[
d_j=\delta_{n+j}\quad(0\le j\le r),
\qquad
\Omega_{n,r}=\frac{\omega_{n+r}}{\omega_n}.
\]

Multiplication of (2) gives

\[
\begin{aligned}
\prod_{j=0}^{r-1}
(\epsilon_{n+j}^2+\phi_{n+j}^2)
&=
\Omega_{n,r}
\prod_{j=0}^{r-1}
\frac{(1-d_j)(1-d_{j+1})}{d_{j+1}}\\
&=
\Omega_{n,r}
\frac{(1-d_0)(1-d_r)}
{\prod_{j=1}^{r}d_j}
\prod_{j=1}^{r-1}(1-d_j)^2.
\end{aligned}
\]

Since

\[
\prod_{j=1}^{r}d_j=\frac{V_{n+r}}{V_n},
\]

the exact window formula is

\[
\boxed{
\prod_{j=0}^{r-1}
(\epsilon_{n+j}^2+\phi_{n+j}^2)
=
\frac{\omega_{n+r}V_n}{\omega_nV_{n+r}}
(1-d_0)(1-d_r)
\prod_{j=1}^{r-1}(1-d_j)^2.
}
\tag{3}
\]

The squared interior factors are essential: each interior contraction belongs to two consecutive radius identities. The first and last contractions occur only once.

Put

\[
E_{n,r}=\min_{0\le j<r}\epsilon_{n+j}.
\]

Then

\[
E_{n,r}^{2r}
\le
\prod_{j=0}^{r-1}\epsilon_{n+j}^2
\le
\prod_{j=0}^{r-1}(\epsilon_{n+j}^2+\phi_{n+j}^2).
\]

All factors \(1-d_j\) lie in \([0,1)\). Dropping them from the right of (3) proves (1).

This proof does not require a supremum over recurrence coefficients, an estimate for every intermediate inverse matrix, or a choice of a different Gram.

\subsubsection{2. The sharper bound from the same four endpoint volumes}\label{endpoint-user_product_original--the-sharper-bound-from-the-same-four-endpoint-volumes}

For \(r\ge2\), define the three endpoint ratios

\[
\alpha=\frac{V_n}{V_{n-1}},\qquad
\beta=\frac{V_{n+r}}{V_{n+r-1}},\qquad
t=\frac{V_{n+r-1}}{V_n}.
\]

Thus

\[
d_0=\alpha,\qquad d_r=\beta,\qquad
\prod_{j=1}^{r-1}d_j=t,
\]

with \(0<\alpha,\beta,t\le1\). Also retain the attachment's norm factor

\[
\mathcal A_{n,r}
=
\left(\frac{\omega_{n+r}}{\omega_n}\right)^{1/(2r)}.
\]

The sharpened theorem is

\[
\boxed{
E_{n,r}\le\mathcal U_{n,r},
}
\tag{4}
\]

where

\[
\boxed{
\mathcal U_{n,r}
=
\mathcal A_{n,r}
\left(
\frac{(1-\alpha)(1-\beta)}{\beta t}
\right)^{1/(2r)}
\left(1-t^{1/(r-1)}\right)^{(r-1)/r}.
}
\tag{5}
\]

Only

\[
V_{n-1},\quad V_n,\quad V_{n+r-1},\quad V_{n+r},
\qquad
\omega_n,\quad\omega_{n+r}
\]

are needed---the same endpoint data used in the attachment. Its existing criterion combines the four volumes into one logarithmic budget; (5) retains their separate contributions.

\paragraph{Proof}\label{endpoint-user_product_original--proof}

Let \(s=r-1\). For positive contractions \(d_1,\ldots,d_s\le1\) with product \(t\),

\[
\boxed{
\prod_{j=1}^{s}(1-d_j)
\le
(1-t^{1/s})^s.
}
\tag{6}
\]

If a \(d_j=1\), the left side is zero, so the inequality is immediate. Otherwise set \(v_j=-\log d_j>0\). The function

\[
f(v)=\log(1-e^{-v})
\]

has

\[
f''(v)=-\frac{e^{-v}}{(1-e^{-v})^2}<0.
\]

Jensen's inequality gives

\[
\sum_{j=1}^{s}\log(1-e^{-v_j})
\le
s\log\left(1-e^{-(v_1+\cdots+v_s)/s}\right).
\]

Exponentiating and using \(e^{-\sum v_j}=t\) proves (6). This is an application of the ordinary concavity form of Jensen's inequality, not a new general inequality (National Institute of Standards and Technology {[}NIST{]}, n.d.-b, §1.7(iv)). (\href{https://dlmf.nist.gov/1.7?utm_source=chatgpt.com}{DLMF})

Insert (6) into (3):

\[
\prod_{j=0}^{r-1}
(\epsilon_{n+j}^2+\phi_{n+j}^2)
\le
\Omega_{n,r}
\frac{(1-\alpha)(1-\beta)}{\beta t}
(1-t^{1/s})^{2s}.
\]

Taking the nonnegative \(2r\)-th root proves (4)--(5). \(\square\)

For \(r=1\), there is no interior product and no fractional exponent involving \(r-1\). The separate formula is simply

\[
\boxed{
\epsilon_n
\le
\sqrt{\frac{\omega_{n+1}}{\omega_n}}\,
\sqrt{(1-\alpha)(\beta^{-1}-1)}.
}
\tag{7}
\]

It retains the exact contraction contribution at that single step.

\paragraph{Comparison with the attached criterion}\label{endpoint-user_product_original--comparison-with-the-attached-criterion}

The attachment proves

\[
E_{n,r}\le
\mathcal A_{n,r}
\sinh\!\left(\frac{\mathcal B_{n,r}}{2r}\right),
\qquad
\mathcal B_{n,r}
=
\log\frac{V_{n-1}V_n}{V_{n+r-1}V_{n+r}}.
\]

Its proof first replaces each exact contraction product by a hyperbolic-sine square and then applies Jensen.

The new endpoint expression satisfies

\[
\boxed{
\mathcal U_{n,r}
\le
\mathcal A_{n,r}
\sinh\!\left(\frac{\mathcal B_{n,r}}{2r}\right).
}
\tag{8}
\]

To see this, fix the four endpoints. Equation (6) shows that the product of the exact local contraction terms is maximized when all interior ratios equal \(t^{1/(r-1)}\). Apply the attachment's local upper inequality and its Jensen inequality to that maximizing scalar sequence. Their endpoint budget is still exactly \(\mathcal B_{n,r}\), so their upper bound dominates the maximum used in (5). Degenerate cases follow directly or by continuity.

A useful explicit comparison occurs for geometric volume contraction:

\[
V_{n+j}=V_{n-1}d^{j+1},\qquad d=e^{-v}\in(0,1).
\]

Then

\[
\alpha=\beta=d,\qquad t=d^{r-1},
\]

and (5) becomes

\[
\boxed{
\mathcal U_{n,r}
=
\mathcal A_{n,r}\frac{1-d}{\sqrt d}
=
2\mathcal A_{n,r}\sinh(v/2).
}
\tag{9}
\]

The previous bound is \(\mathcal A_{n,r}\sinh v\). Their ratio is

\[
\frac{\text{previous bound}}{\mathcal U_{n,r}}
=\cosh(v/2).
\]

The improvement can therefore be substantial, rather than merely a rearrangement of the same estimate.

\paragraph{Exact scope of sharpness}\label{endpoint-user_product_original--exact-scope-of-sharpness}

Equation (5) is sharp for the \textbf{relaxed scalar problem} consisting of positive norm sequences, nonincreasing positive volume sequences, and identity (2).

For strictly contracting endpoints, choose all interior \(d_j=t^{1/(r-1)}\). Write

\[
f_j=(1-d_j)(d_{j+1}^{-1}-1)>0.
\]

Set

\[
\frac{\omega_{n+j+1}}{\omega_{n+j}}
=\frac{\mathcal U_{n,r}^2}{f_j},
\qquad
\phi_{n+j}=0,\qquad
\epsilon_{n+j}=\mathcal U_{n,r}.
\]

The product of the specified norm ratios is exactly \(\Omega_{n,r}\), so the prescribed norm endpoints are respected and equality holds.

This is \textbf{not} an assertion that every such extremizing scalar sequence arises from the arithmetic convolution measure. The additional moment, recurrence, and interpolation constraints of that measure remain relevant.

\paragraph{Neither the phase nor the interior imbalance needs to be forgotten}\label{endpoint-user_product_original--neither-the-phase-nor-the-interior-imbalance-needs-to-be-forgotten}

With all interior contractions strictly below one, define the nonnegative concavity loss

\[
\mathcal J_{n,r}
=
(r-1)\log(1-t^{1/(r-1)})
-\sum_{j=1}^{r-1}\log(1-d_j).
\]

Equation (3) becomes the exact identity

\[
\boxed{
\prod_{j=0}^{r-1}
(\epsilon_{n+j}^2+\phi_{n+j}^2)
=
\mathcal U_{n,r}^{2r}e^{-2\mathcal J_{n,r}}.
}
\tag{10}
\]

Thus the additional loss in passing to the endpoint bound is explicitly recorded.

For example, when the phases have been calculated, the sharper conclusion is

\[
\boxed{
\prod_{j=0}^{r-1}
(E_{n,r}^2+\phi_{n+j}^2)
\le
\mathcal U_{n,r}^{2r}e^{-2\mathcal J_{n,r}}.
}
\tag{11}
\]

The left side is an increasing polynomial in \(E_{n,r}^2\). Its unique nonnegative threshold gives a phase-sensitive bound. No phase is presumed to vanish at a general auxiliary tilt.

\subsubsection{3. The simpler corollary reduces to a ratio of two determinant sequences}\label{endpoint-user_product_original--the-simpler-corollary-reduces-to-a-ratio-of-two-determinant-sequences}

The quantity in (1) admits a cancellation that reduces the number of endpoint objects further. Define

\[
\Lambda_N=\frac{\omega_N}{V_N}.
\]

The supplied source formulas are

\[
\omega_N=\frac{\mathfrak D_{N+1}}{\mathfrak D_N},
\qquad
V_N=\frac{\mathfrak D_{N+1}}{\mathfrak B_{N-q+1}}.
\]

They use the original source and relation Gram determinants. The ordinary monic-norm and moment-determinant framework is also recorded in DLMF §18.2(iv), (ix); the arithmetic identification of the relation determinant is the supplied construction. (\href{https://dlmf.nist.gov/18.2?utm_source=chatgpt.com}{DLMF})

Consequently,

\[
\boxed{
\Lambda_N=\frac{\mathfrak B_{N-q+1}}{\mathfrak D_N}.
}
\tag{12}
\]

The source determinant \(\mathfrak D_{N+1}\) cancels literally. Equation (1) is therefore

\[
\boxed{
E_{n,r}
\le
\left(
\frac{\Lambda_{n+r}}{\Lambda_n}
\right)^{1/(2r)}
=
\left(
\frac{
\mathfrak B_{n+r-q+1}\mathfrak D_n
}{
\mathfrak D_{n+r}\mathfrak B_{n-q+1}
}
\right)^{1/(2r)}.
}
\tag{13}
\]

This uses two source determinants and two relation determinants. It does not identify the relation space with its quotient value.

The mass bookkeeping remains exact. Rescaling the fixed source measure by \(c>0\) would give

\[
\omega_N\mapsto c\omega_N,\qquad
V_N\mapsto c^qV_N,\qquad
\Lambda_N\mapsto c^{1-q}\Lambda_N.
\]

Hence \(\Lambda_{n+r}/\Lambda_n\) is unchanged. No rescaling is performed; this calculation explains the cancellation while retaining the original mass.

\paragraph{Connection to the confluent-transfer interface}\label{endpoint-user_product_original--connection-to-the-confluent-transfer-interface}

The attachment supplies

\[
V_N=
\left(\prod_{j=a}^{N}\omega_j\right)
\frac{\det\mathsf V}{\det F_a},
\qquad a=N-q+1,
\]

with the full confluent-jet conventions retained.

It follows that

\[
\Lambda_N
=
\frac{\det F_a}
{\det\mathsf V\displaystyle\prod_{j=a}^{N-1}\omega_j}.
\]

For \(a=n-q+1\), equation (13) becomes

\[
\boxed{
E_{n,r}
\le
\left[
\frac{\det F_{a+r}}{\det F_a}
\prod_{j=0}^{q-2}
\frac{\omega_{a+j}}{\omega_{a+r+j}}
\right]^{1/(2r)}.
}
\tag{14}
\]

At \(q=1\), the product is empty and equals one.

Thus the simpler criterion requires \textbf{two transfer determinants}, rather than four, together with the displayed norm bands. The common confluent Vandermonde factor cancels through an explicit ratio. No modulus is inserted to conceal a phase: positivity of the total expression follows from its equality with \(\Lambda_{n+r}/\Lambda_n>0\).

The supplied exterior result gives

A sufficient asymptotic estimate is now

These are still estimates to prove for the actual arithmetic family. The deduction specifies their required scale; it does not derive them from determinant positivity.
