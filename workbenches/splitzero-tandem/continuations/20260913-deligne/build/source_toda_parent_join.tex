\subsubsection{Complete loss identity}\label{toda_parent_join:complete-loss-identity}

The Toda identity gives

a\_(N+1) sinh(s\_N)\^{}2 - epsilon\_N\^{}2 = a\_(N+1) (exp(t\_N)-cosh(s\_N))\^{}2 + phi\_N\^{}2.

The companion's E8 gives, on the same original metric,

epsilon\_N\^{}2 - L\^{}2 = \textbar\textbar C\_N\textbar\textbar\_(HS,G\_N)\^{}2 + epsilon\_N\^{}2
(det M\_N + det(I\_2-M\_N)).

Adding these equalities cancels precisely epsilon\_N\^{}2 and proves

\textbf{a\_(N+1) sinh(s\_N)\^{}2 - L\^{}2 = a\_(N+1) (exp(t\_N)-cosh(s\_N))\^{}2 + phi\_N\^{}2 +
\textbar\textbar C\_N\textbar\textbar\_(HS,G\_N)\^{}2 + epsilon\_N\^{}2 (det M\_N +
det(I\_2-M\_N)).}

All four terms on the right are nonnegative. The first two are the successive-volume imbalance and
the retained phase. The last two are the original spectral-subspace coupling and the compression
remainder. There is no cancellation between them.

\subsubsection{What this adds to the two-step
inequality}\label{toda_parent_join:what-this-adds-to-the-two-step-inequality}

Let R\_N = V\_(N-1)/V\_(N+1) = exp(2s\_N). Dropping only the imbalance square and the nonnegative

a\_(N+1) (R\_N-1)\^{}2/(4 R\_N) \textgreater= L\^{}2 + phi\_N\^{}2 +
\textbar\textbar C\_N\textbar\textbar\_(HS,G\_N)\^{}2.

log R\_N \textgreater= 2 arsinh( sqrt(L\^{}2 + phi\_N\^{}2 +
\textbar\textbar C\_N\textbar\textbar\_(HS,G\_N)\^{}2) / sqrt(a\_(N+1))).

For a full quartet at zero tilt, the supplied symmetry proves phi\_N = 0; the coupling term is still
