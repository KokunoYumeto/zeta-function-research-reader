# Source–boundary volume dynamics for the arithmetic control

Open `index.html` for the self-contained MathML reader. `NOTE.tex` and `RESEARCH_NOTE.md` contain the complete derivation. `HANDOFF.md` specifies bounded targets for the parallel formalization session.

Main result: the SAME canonical finite arithmetic control can be computed from two exact Hankel determinant sequences generated by one arithmetic Laplace transform. Its original complex cross term is a derivative of the quotient-volume determinant. A finite two-step volume upper bound follows, with both losses retained. The existing exterior trace lower bound then forces a quantified volume contraction for an off-line quartet.

This does not prove a uniform subcubic upper estimate or RH. The determinant representation does not remove numerical conditioning. The original split scalar support, infinite quotient, source relation, full unit, and cohomological maps remain in the note.

Run `python check_toda_volume.py --json checks/normal.json` for the exact finite regression suite. `python -O` is also supported. `--fail-control` is a deliberately failing test of the checker path. `evaluate_seed.py` performs separate numerical arithmetic-seed evaluations, not interval certification. `build_reader.py` uses Pandoc to rebuild HTML and LaTeX; no external JavaScript is required to read the HTML.
