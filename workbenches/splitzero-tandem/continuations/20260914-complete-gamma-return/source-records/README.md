# Source identities and historical locators

CURRENT_SOURCE_PINS.json identifies the unchanged final 15-page PDF, its complete LET/PHT/HCT compiled closure and author originals, and the complete current NOTE/JSR/WRC receiver. Mathematical bodies, Lean/code, proof diffs and their coordinates are unchanged.

In named current metadata, guide and compiler-record copies, `[[user]]` replaces only the private account component of historical absolute locators. It is not an actual build path. Public copies inherited from cuts18/19 keep their already documented `source-records/local-user` origin aliases or retained-author relative locators. The per-file ledger identifies which source edition supplied each copy.

provenance/public_predecessors contains the exact historical public inventories, derivation ledgers and copy receipts for those editions. Their member paths are relative to their original public editions, not automatically to this directory; this cut's PUBLIC_DERIVATION.json supplies the actual old-to-new file map. Owner receipts and embedded hashes retain their original, pre-redaction identity semantics. New public metadata derivatives have separately recorded current identities.

The predecessor text closure preserves its historical guides. Their references to earlier PDFs refer to the earlier editions: the owner explicitly omitted 50 duplicate PDF/ZIP/PNG assets from this textual dependency copy while preserving every proof. That omission list is retained in provenance/DEPENDENCY_COPY_RECEIPT.json. This public derivative additionally excludes only the same two known private pasted messages and does not copy the outer owner ZIP.
