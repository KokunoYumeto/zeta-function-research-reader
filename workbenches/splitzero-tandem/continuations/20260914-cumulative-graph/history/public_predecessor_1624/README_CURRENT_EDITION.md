# Split-Zero cohomology and arithmetic weight control

This cumulative edition carries the later source, mixed-support, boundary and metric calculations into their earlier proof sites and their downstream uses. The editable reader is `tex/main.tex`; the complete current proof bodies are included from `tex/` and the explicitly revised prepared source notes in `build/`.

Build the current manuscript with:

    python scripts/build_paper.py

The build requires XeLaTeX, the fonts and packages declared in the main file, and PyMuPDF for recording the page count. The reader compiles from the files in this repository without a network connection or an external workspace. Its source pins are checked before compilation. The default entrypoint does not replay historical source-preparation adapters, because doing so could restore superseded proof text.

Earlier exact source versions remain available in `sources/`, `history/` and `provenance/`. The original 821-page edition is an unchanged historical source cut. The current source map distinguishes each accepted mathematical revision from mechanical TeX presentation changes and records exact inverse transformations for those changes. Complete original source documents are retained even when an identical proof is printed once through an explicit source-equivalence route.

The complete source chronology accompanies the mathematical chapters. Historical statements about available results or remaining work refer to their own source dates. Current mathematical statements and refinements appear in the revised proof chapters and current conclusion. Publication history and historical hashes are not assigned to later revised text.

The exact final source/PDF identities and exhaustive page review are recorded separately in the final manifest and validation receipts after compilation. This file alone makes no source-seal or visual-acceptance claim.
