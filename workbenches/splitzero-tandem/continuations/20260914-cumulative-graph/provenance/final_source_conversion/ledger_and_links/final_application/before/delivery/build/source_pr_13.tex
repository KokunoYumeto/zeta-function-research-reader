\subsubsection{6. The same source proves a strong topology

Poisson gives h(z)=h(-z), so the same holds at the other end. Fourier contour displacement therefore

complex measure with a smaller positive exponential moment. Its Fourier transform is analytic in a

weighted space onto L2(dt/(2 pi)), because the nonzero analytic function g on the line is nonzero
almost everywhere. This proves the assertion without RH.
