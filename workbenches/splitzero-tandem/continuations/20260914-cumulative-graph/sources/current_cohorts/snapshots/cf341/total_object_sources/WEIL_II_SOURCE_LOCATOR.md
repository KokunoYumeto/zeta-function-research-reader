In lemma 1.8.1 the trace-formula denominator is the determinant on H_c^2. The historical complete English math-mode source prints H^0 at this point, whereas the current S20 text prints H_c^2. The amplification note uses H_c^2, checked against the current text. Neither historical nor current source was changed. This concrete discrepancy is why the historical math-mode witness is not represented as the current corrected edition.
