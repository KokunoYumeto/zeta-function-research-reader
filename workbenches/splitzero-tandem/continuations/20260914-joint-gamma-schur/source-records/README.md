# Historical source locators

`source-records/local-user/...` is a stable relative origin alias used only in copied historical metadata, guides and execution logs. It does not assert that the named historical file is bundled here or that a historical command is the current build command. The original local prefix is intentionally not public. PUBLIC_DERIVATION.json records its digest, each affected file and occurrence count.

The seven active author-source paths in ACCEPTED_SOURCE_PINS.json instead point to the actual retained files under provenance/math_sources/. Their author hashes are unchanged. The prepared sources/ files printed in the PDF are separately bound by CURRENT_SOURCE_PINS.json and the owner final build receipt.

Private pasted messages and the raw incoming ZIP remain in the private owner delivery. Their hashes and dispositions are retained without publishing their contents.
