# Historical source locators

The five active author paths in ACCEPTED_SOURCE_PINS.json point to the actual unchanged author originals under provenance/math_sources/. CURRENT_SOURCE_PINS.json separately binds the final prepared source bodies, whole receivers, wrapper and 33-page PDF.

`source-records/local-user/...` is a stable origin namespace in copied historical metadata, guides and compiler logs. It is not a claim that every historical path is bundled, nor a current build command. Each exact prefix substitution and original file hash is recorded in PUBLIC_DERIVATION.json. All mathematical bodies, code, proof diffs and original PDF bytes remain unchanged.

The complete public cut-18 dependency under dependencies/joint_schur_46/ is reused byte for byte with its own source-records note and derivation ledger. That predecessor ledger records the inherited private pasted-text and original-archive exclusions. The owner cut-19 archive is not copied because it includes those same local records.

Embedded hashes in historical receipts still identify the original recorded bytes. They are not silently changed to hashes of public metadata derivatives. The current public inventory gives each derivative its own identity.
