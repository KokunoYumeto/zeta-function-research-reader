To build the main reader, run the following command three times from this folder using XeLaTeX, with Cambria, Calibri and Consolas installed:

```text
xelatex -interaction=nonstopmode -halt-on-error -file-line-error Original_Gamma_Volumes_and_Intrinsic_Spectral_Sums.tex
```

For the cumulative editable entry, substitute `Cumulative_Original_Gamma_Proofs.tex`. Its compilation check uses the additional option `-no-pdf`.
