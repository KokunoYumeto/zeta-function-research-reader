\section{The actual arithmetic packet through mixed-support synchronization}
\label{sec:original-mixed-support-packet-retract}

This calculation starts with the mixed-support construction in original
shared-thread record A0961, node
\texttt{a7bbd422-311c-4380-ba6c-a4bdd61fce2f}, chain 2032,
and its full authored proof in original record A0953, node
\texttt{0d2934ea-14ac-48c1-a1f3-cd918c1f5fe5}, chain 1987.
It does not replace the actual arithmetic function by a symmetric test
polynomial. The polynomial below is the full divisor polynomial of
an actual packet in the counterfactual under study.

Let $Z$ be a nonempty finite set of actual nontrivial zeros of the original
completed function $g(s)=2\xi(s)$, with their full orders $m_\rho$.
Retain
\[
 h_Z(x)=\prod_{\rho\in Z}(x-\rho)^{m_\rho},\qquad
 d=\sum_{\rho\in Z}m_\rho,\qquad
 E_Z=\mathbb C[x]/(h_Z(x)).
\]
The variable $x$ is the original spectral variable. The additional
variable $t$ below is the cyclic coefficient coordinate; it is not
substituted for $x$.
For $a>0$ let
\[
 A_a=M_{j_{h_Z}(a^s)}:E_Z\longrightarrow E_Z.
\]
Here $a^s=\exp(s\log a)$ uses the real logarithm and $j_{h_Z}$ retains
all Taylor coefficients at the actual zero centres. On the summand
\[
 E_\rho=\mathbb C[z_\rho]/(z_\rho^{m_\rho}),\qquad
 x=\rho+z_\rho,
\]
this is exactly
\begin{equation}
 A_a|_{E_\rho}=a^\rho
 \sum_{j=0}^{m_\rho-1}\frac{(\log a)^j}{j!}N_\rho^j,
 \qquad N_\rho=M_{z_\rho}.
 \label{eq:original-packet-full-action}
\end{equation}
Thus no multiplicity or nilpotent term is omitted.

\subsection{The original mixed-support object, with its unit}

Fix $n\ge1$. Form the source object $D_{E_Z,n}=G(E_Z)^n$ with
coordinatewise addition and the source product
\[
 (b\star c)_k=
 \bigoplus_{i+j=k}b_ic_j\ \oplus\!
 \bigoplus_{i+j=k+n}(-1)^\bullet b_ic_j,
 \qquad 0\le k<n.
\]
An empty sum is $\tau$, and the original unit is
$(1^\bullet,\tau,\ldots,\tau)$. Write $e=0_{E_Z}^\bullet$.
The exact amplitude target is
\[
 B_n=E_Z[t]/(t^n+1),\qquad
 \pi_n(b)=\sum_{i=0}^{n-1}p(b_i)t^i.
\]
The support mask of $b$ has its $i$th entry equal to one precisely when
$b_i\ne\tau$. The pair consisting of the mask and $\pi_n(b)$ is injective:
the monic polynomial gives the free $E_Z$-basis $1,t,\ldots,t^{n-1}$,
and the mask then distinguishes $e$ from $\tau$ in each zero coefficient.

Let
\[
 \mathsf E_n=(1^\bullet,e,\ldots,e).
\]
Multiplication by $\mathsf E_n$ sends the wholly absent input to itself
and every active input to the fully supported vector with the same
ordinary coefficients. To check the support assertion, fix an active
input coefficient at index $j$. At every output index $k$ the summand
using the $\mathsf E_n$ coefficient at $k-j$ modulo $n$ is supported;
all wrap factors are supported. Thus every output coordinate is
supported, including a coordinate whose resulting amplitude is zero.
The amplitude assertion follows from $\pi_n(\mathsf E_n)=1$.
It follows at once that $\mathsf E_n^2=\mathsf E_n$ and
\begin{equation}
 D_{E_Z,n}[\mathsf E_n^{-1}]
 \simeq \mathsf E_nD_{E_Z,n}
 \simeq G(B_n).
 \label{eq:original-sync-localization}
\end{equation}
The image has unit $\mathsf E_n$. For completeness, a unital semiring
map making $\mathsf E_n$ invertible sends it to 1 by idempotence and
therefore sends $b$ and $\mathsf E_nb$ to the same value. This is the
localization universal property. The inclusion of the image into the
original unsynchronized object is not falsely declared to preserve
the original unit.

\subsection{A proved split injection and its exact retraction}

Define
\[
 \iota_n:E_Z\longrightarrow B_n,\quad f\longmapsto f,
 \qquad
 r_n:B_n\longrightarrow E_Z,\quad
 b\longmapsto\frac1n\operatorname{Tr}_{B_n/E_Z}(M_b).
\]
The first is a unital ring homomorphism. The second is an
$E_Z$-linear map of modules; it is not asserted to be multiplicative.
In the basis $1,t,\ldots,t^{n-1}$, multiplication by $t^k$ has no
diagonal entries for $1\le k<n$, since it shifts every basis index
by the nonzero class $k\pmod n$. Its wrap entries carry the original
minus signs. Multiplication by $b_0\in E_Z$ is the scalar matrix
with $n$ diagonal entries $b_0$. Consequently
\begin{equation}
 \operatorname{Tr}_{B_n/E_Z}
   \left(M_{\sum_{i=0}^{n-1}b_it^i}\right)=nb_0,
 \qquad
 r_n\left(\sum_{i=0}^{n-1}b_it^i\right)=b_0,
 \qquad r_n\iota_n=1_{E_Z}.
 \label{eq:original-trace-retract}
\end{equation}
In particular the trace factor $n$ and its inverse in the retraction
are both retained. No arithmetic trace form has been rescaled.

For a linear map $T:M\to N$ over $E_Z$, its split lift is
$T^\tau(m^\bullet)=T(m)^\bullet$ and $T^\tau(\tau)=\tau$.
It is $G(E_Z)$-linear: addition of supported inputs is the original
module addition, scalar multiplication is the original module action,
and the cases containing an absent scalar or input are absorbed by
$\tau$. A zero result is $(0_N)^\bullet$, not $\tau$.
Thus \eqref{eq:original-trace-retract} lifts to an actual retract
\begin{equation}
 E_Z^\tau\xrightarrow{\iota_n^\tau}G(B_n)
 \xrightarrow{r_n^\tau}E_Z^\tau,
 \qquad r_n^\tau\iota_n^\tau=1.
 \label{eq:original-split-retract}
\end{equation}
Through \eqref{eq:original-sync-localization}, the first map is the
fully supported mixed vector $(f^\bullet,e,\ldots,e)$ for supported
$f$, and the wholly absent vector for $\tau$. Therefore every
nonzero amplitude packet class remains nonzero through this specific
mixed-support realization and localization.

Write $\sigma_Z:E_Z\hookrightarrow Q$ and $J_Z:Q\to E_Z$ for
the original arithmetic packet injection and observation, whose
proved identity is $J_Z\sigma_Z=1_{E_Z}$. Their composite with the
maps just computed is
\[
 \sigma_Zr_n:B_n\longrightarrow Q,\qquad
 (\sigma_Zr_n)\iota_n=\sigma_Z.
\]
This is a composite of the established maps, not a new assertion that
the spectral coefficients are unrelated to arithmetic cohomology.

The scaling intertwiner used here comes from the original source.
Retain $Q=\mathscr B/\Theta V$, $D=-x\partial_x$, and

 (\mathcal R_aF)(x)=F(x/a),\qquad a>0.

Thus $\mathcal R_a$ induces the original action $\overline{\mathcal R}_a$

 \mathcal M(\mathcal R_aF)(s)=a^s\mathcal MF(s),\qquad

\subsection{The exact coefficient Frobenius comparison}

Let $q$ be an odd prime power with $\gcd(q,n)=1$.
On the integral coefficient algebra
\[
 C_{n,\mathbb Z}=\mathbb Z[t]/(t^n+1)
\]
define the unital algebra map
\[
 \Psi_q(t)=t^q,\qquad \Psi_q(c)=c\quad(c\in\mathbb Z).
\]
It is well-defined since $(t^q)^n=(-1)^q=-1$.
Because $\gcd(q,2n)=1$, choose $r>0$ with $q^r\equiv1\pmod{2n}$.
The identity $t^{2n}=1$ then gives $\Psi_q^r=1$, proving it is an
automorphism. Its matrix in the original coefficient basis is the
signed permutation
\begin{equation}
 t^i\longmapsto(-1)^{\lfloor qi/n\rfloor}t^{qi\bmod n}.
 \label{eq:original-integral-frob-matrix}
\end{equation}
Reduction of this integral map to $\mathbb F_q$ is exactly the
source's $q$-power Frobenius on $\mathbb F_q[t]/(t^n+1)$, because
every scalar of $\mathbb F_q$ has $q$th power equal to itself.
Its extension to $\mathbb C$ is a coefficient-linear lift of that
integral matrix. It is not the map $c\mapsto c^q$ on complex scalars.
These two specializations are linked by the displayed integral map;
no ring homomorphism $\mathbb F_q\to\mathbb C$ is asserted.

There is also a map on the full unsynchronized mixed-support object:
send coefficient $b_i$ to
$\bigl((-1)^\bullet\bigr)^{\lfloor qi/n\rfloor}b_i$ in slot $qi\bmod n$,
fixing $E_Z$ scalars and preserving absent inputs. It is additive.
On two supported monomials, reducing the exponent before or after
the map gives the same wrap factor because $((-1)^\bullet)^q=(-1)^\bullet$;
the absent cases are absorbed, and distributivity proves the product
identity for arbitrary vectors. Hence this is a semiring morphism,
fixes $\mathsf E_n$, preserves every mask up to the stated permutation,
and induces $\Psi_q$ through \eqref{eq:original-sync-localization}.

Extend $\Psi_q$ $E_Z$-linearly to $B_n$. It fixes the subspace
$\iota_n(E_Z)$ pointwise. It preserves $r_n$: formula
\eqref{eq:original-integral-frob-matrix} moves no index
$i\in\{1,\ldots,n-1\}$ to zero modulo $n$, and fixes index zero.
Hence
\begin{equation}
 \Psi_q\iota_n=\iota_n,\qquad r_n\Psi_q=r_n.
 \label{eq:original-frob-retract}
\end{equation}
Every eigenvalue of the complex coefficient operator $\Psi_q$ is
a root of unity, because $\Psi_q^r=1$. Over $\mathbb C$ the
polynomial $X^r-1$ has no repeated roots, so the operator is
diagonalizable. This is the exact finite coefficient purity
calculation transported through its integral matrix.

\subsection{The original arithmetic action, full jets, and modulus}

Extend $A_a$ to $B_n$ by coefficient multiplication:
\[
 A_a^{B}\left(\sum b_it^i\right)=\sum A_a(b_i)t^i.
\]
Since $A_a$ is multiplication by $j_{h_Z}(a^s)\in E_Z$,
this commutes with the $E_Z$-linear automorphism $\Psi_q$.
The maps in \eqref{eq:original-trace-retract} intertwine the
arithmetic action exactly:
\[
 A_a^B\iota_n=\iota_n A_a,\qquad
 r_n A_a^B=A_a r_n.
\]
Consequently they also intertwine $A_a$ with
$A_a^B\Psi_q$ because of \eqref{eq:original-frob-retract}.
On the coefficient eigenspace of $\Psi_q$ with eigenvalue
$\omega$, the original $\rho$-packet action is
\begin{equation}
 \omega a^\rho
 \sum_{j=0}^{m_\rho-1}\frac{(\log a)^j}{j!}N_\rho^j.
 \label{eq:original-joint-action}
\end{equation}
The entire nilpotent polynomial is retained. For $a\ne1$, its
nilpotent part has the same nilpotence index as $N_\rho$:
\[
 \exp((\log a)N_\rho)-1
 =N_\rho\left((\log a)I+
 \sum_{j=2}^{m_\rho-1}\frac{(\log a)^j}{j!}N_\rho^{j-1}\right),
\]
and the factor in parentheses is invertible because its constant
coefficient is nonzero. The expression also states the case
$m_\rho=1$ directly.

Let $e_\rho$ be the full Chinese-remainder idempotent in $E_Z$.
The vector
\[
 v_\rho=e_\rho(x-\rho)^{m_\rho-1}
\]
is nonzero: in its $\rho$-local quotient its coefficient of
$z_\rho^{m_\rho-1}$ is one. It is killed by $N_\rho$ and satisfies
$A_av_\rho=a^\rho v_\rho$. The vector $\iota_n(v_\rho)$ is
nonzero by the retraction, lies in the fixed coefficient line of
$\Psi_q$, and is therefore an eigenvector of $A_a^B\Psi_q$ with
the unchanged eigenvalue $a^\rho$.

Suppose now the actual counterfactual supplies
$\rho=\tfrac12+\delta+i\gamma$, $0<\delta<\tfrac12$.
For every $a>1$,
\begin{equation}
 \frac{|a^\rho|^2}{a}=a^{2\delta}>1,
 \qquad
 \log\frac{|a^\rho|^2}{a}=2\delta\log a.
 \label{eq:original-surviving-defect}
\end{equation}
For the other coefficient eigenspaces in
\eqref{eq:original-joint-action}, $|\omega|=1$ gives exactly the
same modulus. At $a=q$, these eigenvalues are $q^\rho\omega$.
The coefficient pure spectrum therefore preserves the actual
arithmetic weight defect in this specified construction.

Take every tensor power in this paragraph over $\mathbb C$.
The vector $\iota_n(v_\rho)^{\otimes_{\mathbb C} k}$
is nonzero because $(r_n)^{\otimes_{\mathbb C} k}$ sends it to
$v_\rho^{\otimes_{\mathbb C} k}$. The latter is nonzero: a
complex linear functional taking $v_\rho$ to 1 has $k$-fold complex
tensor power taking that tensor to 1.
Its eigenvalue under $(A_a^B\Psi_q)^{\otimes_{\mathbb C} k}$ is $a^{k\rho}$,
and
\[
 \log\frac{|a^{k\rho}|^2}{a^k}=2k\delta\log a.
\]
This is an exact input to the user's selected Deligne amplification
argument. The computation does not import a cohomological upper
estimate from another object. It identifies which actual nonzero
class and which unchanged eigenvalue such an estimate must control.

\subsection{The trace obstruction also survives the pure coefficient factor}

Assume $Z$ is stable under $\rho\mapsto1-\bar\rho$ and under
conjugation, with the original multiplicities. Retain the actual
derivative-residue trace contraction
\[
 \mathcal T_Z(f,u)=\sum_{\rho\in Z}
 m_\rho\overline{f(1-\bar\rho)}u(\rho).
\]
This formula is the contraction of the original residue pairing
using $g'$; the factors in $g=2\xi$ are not modified here.
In a genuine off-line quartet let $m$ be its common multiplicity
and set $f=e_\rho-e_{1-\bar\rho}$. The two nonzero evaluations
contribute $-m$ each, so $\mathcal T_Z(f,f)=-2m$.

On $C_n=\mathbb C[t]/(t^n+1)$ retain the positive form
\[
 H_n(c,d)=\sum_{j=0}^{n-1}\overline{c(r_j)}d(r_j),
 \qquad r_j=\exp\left(\frac{(2j+1)\pi i}{n}\right).
\]
The distinct roots make evaluation an isomorphism
$C_n\simeq\mathbb C^n$, proving positive definiteness. The
operator $\Psi_q$ permutes the evaluations, so it preserves $H_n$.
The original constant vector has $H_n(1,1)=n$.
Under $B_n\simeq E_Z\otimes_{\mathbb C}C_n$ the tensor form
therefore satisfies
\[
 (\mathcal T_Z\otimes_{\mathbb C} H_n)(\iota_n f,\iota_n f)
 =-2mn<0.
\]
This proves the actual negative trace vector survives this exact
positive coefficient attachment, with the factor $n$ retained.
It does not assert that the global arithmetic polarization is
automatically this tensor form. Any different global comparison
has its own map and must be calculated on this surviving input.
