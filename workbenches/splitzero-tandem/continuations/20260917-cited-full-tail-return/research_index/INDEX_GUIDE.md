# Programme index

`PROGRAM_INDEX.json` is the live machine-readable map of the current research
frontier: exact result statements, proof locations and source hashes,
acceptance records, dependency edges, quantitative scales, programme uses and
unfinished calculations. `FORMULA_LOCATORS.json` indexes displays in the
three specified proof sources; it does not label every formula a theorem.

Coverage is explicit. The preserved 2,343-page omnibus and 3,289-file delivery
have not been shown to be wholly incorporated into the current calculation
reader. That mapping is recorded separately in the edition map. The present
index must not be represented as a complete classification of that corpus.

The final exterior comparison is at q log a. Several accepted estimates
are only o(aq); their stronger use remains a mathematical calculation.

Historical provenance reconstruction is archived by user direction. Human
sources used in new work must be cited at the relevant formulas. This does
not create another retrospective audit programme.
