# Human-source map

This map connects project uses to human works and preserves the difference between a checked formula, a bibliographic identity, and a historical citation. [The machine-readable graph](ATTRIBUTION_GRAPH.json) retains the locators and check levels. It is a growing source record, not a claim that every intellectual debt has been reconstructed.

Every paper's coauthors belong in its citation even when it was discovered on one author's website. An editor of a volume is not automatically a coauthor of a chapter. A person named in a source is not automatically the author of the result used. The [unresolved register](UNRESOLVED_ATTRIBUTION.md) records where a use still lacks an authenticated source or exact theorem.
