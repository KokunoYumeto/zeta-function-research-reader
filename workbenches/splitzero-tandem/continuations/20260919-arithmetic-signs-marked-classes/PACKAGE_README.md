# Reading and checking this source edition

Start with the 95-page arithmetic continuation in `readers/`, then use the
243-page foundation for its preceding full proofs. `PROGRAMME_GUIDE.md`
explains the objects, contributions and unfinished calculations.

Run `python -B verify_package.py` from this folder to check the file allowlist,
source identities, 116 result nodes, 4,956 formula-line destinations, 32 decisive
providers and all six exact predecessor recoveries in the two cumulative
insertion stages. This is an integrity check, not another mathematical proof
audit or Lean execution. No network access is needed.

The complete reader TeX files are in `first_intake/assembly/` and
`arrival_02/assembly/`. The three current cumulative TeX successors are under
`arrival_02/assembly/cumulative/`; their first-intake predecessors are retained
separately. The publisher did not recompile them. The owner's build and visual
QA scope is retained in each final closure and its build receipt.

Original proof and PDF bytes are unchanged. Metadata containing local paths is
a portable derivative, not a byte-identical copy. Use
`SOURCE_PINS_AND_PUBLIC_DERIVATION.json` for both original and public hashes.
For metadata cited as an index source, its public pin is recorded in the index,
its original pin is retained separately, and its line count is unchanged.

Paths beginning `not-bundled/` identify unavailable local records; they are not
download links. Delivery inventories retain input identities and source types
but do not include raw private conversations, unrelated archives or the full
local literature corpus. Human authors and citations remain in the complete
sources and reader bibliographies. The full selected Deligne D032 English
mathematical TeX and the original complete EC provider are included.

No Riemann-hypothesis closure, new global analytical certification of the EC
provider, independent projected sign calculation, or new Zenodo edition is
claimed by this package.
