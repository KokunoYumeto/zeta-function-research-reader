## New results

1. The displaced literal lower-root covariance has an explicit order-q coefficient in both original Gamma orders, with an o(q) remainder. The complete correlated native/conductor/low/compatibility return consequently has its order-q coefficient as well.
2. The order-one/order-k Gamma baseline difference is evaluated through k^2, with O_h(k log q) error. The second coefficient is the explicit negative constant K2=2 log(w^2/(uv))-4 log2.
3. The actual degree-k ambient matched return at the proper-source displaced cutoffs has the explicit displacement -128 q_k log k+C_disp q_k+o(q_k). This is not the proper restriction/quotient value V_Q.
4. The low polynomial intersection of the original observation kernel is determined, cofinally, by five fixed finite original-period jet matrices. On the two-active-coordinate stratum it is zero. The remaining exceptional rank problem is fixed-dimensional and eventually periodic, not a new growing matrix at every tensor order.
5. The exact proper-source cofactor kernel E is annihilated by (x_1x_2x_3x_4)^4. Its support and dimension are bounded using the actual conductor gcd, with all factors retained. On the coprime factor stratum E is zero.
6. On an explicitly described original fixed-period locus containing a finite large-period domain, the original one-step kernel has zero arithmetic invariant core. Its complete packet is recovered by the iterated original observation. The short stack of 8k-15 observations is injective; a q-observation stack has an explicit left inverse with exp(O_{h,u}(q log q)) cost. These two stack statements are not conflated.
