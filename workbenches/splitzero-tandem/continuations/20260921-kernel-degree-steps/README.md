# Split-Zero cohomology: exact changes in the original kernel metric

The Split-Zero programme represents finite zero-divisor classes of the completed Riemann zeta function by polynomials in an arithmetic theta-source Hilbert space. Its observation map leaves a kernel. The metric on that kernel is obtained by minimizing over all original source representatives, with the original arithmetic mass and coefficient maps retained.

This edition calculates how that same metric changes when the admitted polynomial degree increases. The Christoffel–Darboux formula gives every covariance entry, including the reflected-node entries where its quotient expression has a removable denominator. Compression by the original invariant-image frame has an explicit complement correction. The full correction survives in the degree-step formula.

The exact four-cutoff determinant ratio is a product of the degree-step factors. The paired quartet relation proves that its logarithm is strictly positive at every permitted finite degree block. This is a finite strict inequality, not an estimate of its size at the unresolved large-degree kq scale. No RH conclusion or arithmetic-zero identification follows here.
