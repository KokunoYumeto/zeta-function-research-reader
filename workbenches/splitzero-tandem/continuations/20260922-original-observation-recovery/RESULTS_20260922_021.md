# SZ-20260922-021 — finite recovery of the original kernel determinant

The original objects are the source metric \(G_N\), observation \(\Lambda\), conductor kernel \(K=\ker\Lambda\), and arithmetic word \(T\). Every formula uses the four cutoffs \(q-1,q,2q-1,2q\) with signs \(+,+,-,-\).

1. **Every kernel angle has an exact measured receiver.** The zero-frequency matrix \(Y_*=\Lambda P_{\ker T}^{G_N}L_N\) and the original angle matrix have equal positive determinants. MR9–11 prove the eigenspace isometry and all zero/unit multiplicities. On the original transverse domain MR28 proves \(0\le\mathcal K_k-\mathcal R[-\log\det_+Y_*]\le2m\omega_k=o(kq)\). SD6–7 construct examples attaining the bound. SD44–49 recover the native scale from the scalar rational function's leading coefficient, with every finite error retained.
3. **Eight original powers suffice up to an explicit \(O(q)\) determinant.** BD1–3 prove the original 80-power and 128-direction bounds on the retained period domain. BD11 proves a complete-source inequality \(e^{-E_k}G_{q-1}\preceq G_N\preceq G_{q-1}\), with an explicit \(E_k=O_h(q)\). Thus BD22 gives \(0\le\mathcal K_k+\mathcal R\log\det(R_{K,N})_{\rm retained}\le256E_k\).
4. **The polynomial quotient retains all source and phase information.** BD5–10 prove the exact quotient, minimal degrees, whole coefficient-Gram recovery and original source maps.
