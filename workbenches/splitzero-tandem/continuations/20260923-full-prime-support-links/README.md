The positivity bound applies to the specified three-pulse family, not all test functions. Its complete Weil value includes the Archimedean contribution. The signed joint trace is a different, explicitly defined operation; its negative value is not a counterexample to the positive full-Weil values of the individual tests. The local complex weight-one identity does not assert global Deligne purity. The annulus distribution map has its proved source, target and nonzero boundary; no canonical global interior-cohomology identification or RH decision is claimed.
