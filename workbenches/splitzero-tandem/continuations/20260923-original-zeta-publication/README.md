## Separate seven-page source-observation calculation

[Read the integer-heat sampling paper](https://zenodo.org/records/22911829/files/174-splitzero-integer-heat-observation.pdf?download=1) · [Full LaTeX](https://github.com/KokunoYumeto/zeta-function-research-reader/blob/f4fbe917fa82e56ab74065e3eba04197b7f11b97/workbenches/splitzero-tandem/continuations/20260923-integer-heat-observation/NOTE.tex) · [Source and verification guide](https://github.com/KokunoYumeto/zeta-function-research-reader/blob/f4fbe917fa82e56ab74065e3eba04197b7f11b97/workbenches/splitzero-tandem/continuations/20260923-integer-heat-observation/README.md).

For the original Gaussian kernel, all integer samples recover every original coefficient through an explicit inverse and a convergent interpolation kernel. The discrete map carries the supported-zero action, every lower label, independent graph mass and heat evolution. Circle periodization instead forgets the integer coefficient profile and retains the mass. Moving the samples by half an integer preserves uniqueness but destroys a uniform inverse bound; a finite alternating source proves that precise failure. No new metric is substituted for the original arithmetic seminorm.
