# Correction to the general-ring prime-ideal argument

Only the explanatory argument following TS30 is corrected. It previously asserted that products of nonzero ring elements remain nonzero, which is not valid for a ring with zero divisors. The classification itself is unchanged.

The proof now uses the actual retained support labels: if a product has label lambda meet mu in the proper meet-prime lattice ideal J, one factor has its label in J. This label is not the top label, so that factor is the zero-labelled element in Q_J. This proves primality without a domain assumption and covers the same construction over an arbitrary ring.

The author accepted this correction after an independent derivation of TS30–32a. The original nineteen-file edition is retained privately without changes; the corrected edition changes only TWO_SOURCE_SUPPORTED_ZERO.tex and the rebuilt NOTE.pdf among those nineteen files. The arithmetic examples, original-zeta formulas, metrics, certificates, human attributions, result IDs and other proof bodies are unchanged. No new numerical certificate execution or new theorem is claimed.

The exact before-and-after file identities are recorded in PUBLIC_SOURCE_IDENTITY.json. The complete corrected proof is in TWO_SOURCE_SUPPORTED_ZERO.tex; NOTE.tex includes it without changing the master or its other dependencies.
