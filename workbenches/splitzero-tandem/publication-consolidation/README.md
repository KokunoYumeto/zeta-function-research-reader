# Split-Zero cohomology and the zeta-function research programme

[Canonical DOI for all editions](https://doi.org/10.5281/zenodo.22678085) · [This consolidated edition](https://zenodo.org/records/22950644)

This edition brings the original collection and the former continuation back into one version family. The programme studies arithmetic cohomology, original-zeta source maps, spectral and geometric actions, and the estimates needed to relate them to the Riemann hypothesis. It also preserves the connected heat-flow, arithmetic-trace, geometric-complexity, fluid and thermal-geometry investigations, formalization and research self-audit. This is exploratory mathematics, not a proof or disproof of RH.

Start with **154-splitzero-full-support-graph-pulses.pdf**, the established cohomology reader and record preview. The separately readable papers include the full-source tensor, positive-source/original-divisor, arithmetic-return and source-endpoint/residue-section continuations. Their proofs, human-source citations and LaTeX remain in the complete source archives; the original mathematical files are unchanged.

**Everything is retained.** All 98 original PDFs are in 180-original-collection-all-98-papers.zip; selected reading entry points are also separate PDFs. The two original complete source ZIPs remain unchanged. All 36 files from the former continuation are retained, with its cohomology PDF deduplicated against the identical preview PDF. The JSON index records the byte hashes and each file's new location. Every earlier version of that continuation was checked against its last edition; none has extra file content.

GitHub and reader-oriented contributions: https://github.com/KokunoYumeto/zeta-function-research-reader

Existing authorship, per-file rights, source credits and review scopes remain in force. This consolidation verifies file preservation and publication routing; it does not claim a new independent mathematical audit. Earlier published editions in the original family remain citable. New research directions belong here as additional sections, not as a separate project DOI.
