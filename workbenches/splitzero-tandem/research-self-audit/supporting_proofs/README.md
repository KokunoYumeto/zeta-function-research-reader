# Historical proof sources inspected in the audit

These two source files are preserved byte for byte to make the retrospective's citations inspectable. They are historical programme proofs, with their original domains and notation; this publication does not recast them as new results or as new original-zeta reconstructions.

- `Terminal_Adjacent_Window_Standalone.tex`: the original complete integer-window allowance proof, including TCN and TCX arguments and its recorded interval certificate. The retrospective reread TCX1–12, TCN2 and TCN24–31; it did not rerun the old numerical certificate. This file is a standalone LaTeX document.
- `SAME_CLASS_RELATION_ALLOWANCE.tex`: the source chapter containing the exact same-class cancellation. The retrospective reread SCA22–37, including the observation map, Schur identity and full reassembly. This is a chapter source from the original collection, not a separately compiled paper.

The current report gives the mathematical scope, later receiving comparisons and remaining gaps. Neither file proves RH. Their formulas retain the original hypothetical-packet and metric hypotheses. Publishing the evidence is not a claim that all historical analytic dependencies have been independently re-proved in this audit.
