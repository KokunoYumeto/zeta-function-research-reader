# From local extensions to the common ideal: source clarification

The programme combines finitely many local operator-algebra extensions by placing their ideals in fixed orthogonal corners of a common algebra. That particular construction is valid. The historical source catalogue compressed the supporting theorem too far: Blackadar's general construction passes through a Hilbert module and stabilization. It does not assert a literal multiplier extension for every homomorphism in unchanged coordinates.

This supplement supplies the missing explanation. Read the [complete concrete proof](MULTIPLIER_AND_MODULE_PROOF.md), then the [human-source trail](HUMAN_SOURCE_TRAIL.md). The [correction record](CORRECTION_RECORD.json) clarifies catalogue statement `LITSTMT-20260830-0153` while preserving its original hypotheses and historical text. The [bibliography](REFERENCES.bib) records the immediate source and the newly recovered stabilization credits.

The main point is visible in the formula

\[
 \overline\mu_P((m_v)_v)=\sum_{v\in V_P}s_vm_vs_v^*.
\]

This is an explicitly defined, nonunital multiplier map. The tensor-module unitary in the proof identifies it exactly with a permissible realization of the general stabilized construction. No extra nondegeneracy hypothesis is imposed on Blackadar's theorem, and no source theorem is being refuted.

The clarification resolves U10 for this source statement and the identified finite-corner and constant-fibre uses. It is a bounded source-use audit; it does not certify every other extension diagram in the programme or close the wider source register.
