# Checking record

The expanded calculation prepared in this session has a separate 34-check script and numerical examples in the companion conversation package. The public `checks.py` here replays a smaller directly inspectable set of symbolic, finite-operator and high-precision numerical checks for the equations in HARTLE_HAWKING.md. It uses explicit exceptions, so optimization does not disable its checks.

Run `python checks.py` with SymPy and mpmath installed. It prints exactly which assertions were tested, their kinds, and the numerical constants. Its execution record will be added after this exact public file is fetched and run; preparing or publishing code is not an execution claim.

The calculations do not include solving the four-dimensional scalar radial density, integrating the moving detector's finite-switching probability, a Lean build, independent second mathematical review, or a novelty determination. Numerical Mellin examples do not replace the written convergence/transform argument.
