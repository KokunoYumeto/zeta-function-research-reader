# Unified Flow — horizon workbench

A PolyClank workbench connecting physically specified clocks, thermal states, detector response, entropy, spectral data and geometric flow. The first worked system is an eternal Schwarzschild black hole with Hartle–Hawking test fields and explicitly defined probes.

Start with [the worked black-hole calculation](HARTLE_HAWKING.md), [contributions](CONTRIBUTIONS.md), [continuation opportunities](CONTINUE.md), and [the machine-readable record](workbench.json). This directory is self-contained enough to move into an independent repository. Its present home is a proposed sub-workbench of the zeta research reader; that does not make it a proof of RH or a modification of the reader's mathematical claims.

## What we are trying to do

Make the original Unified Flow proposal testable as a network of actual maps: identify the physical system, algebra, state, operator, observable, units and parameter in every step. Preserve proposed connections even where an application remains unconstructed. Do not turn an assumed correspondence into a proved physical identification, or discard an older branch merely because a newer model does not recognize it.

## What this contribution contains

The Hartle–Hawking redshift and modular-action clock; an exact conformal detector peak; the actual four-dimensional scalar scattering problem; the horizon entropy and area response to the selected energy; a round-shell complex Dirac spectrum and its entropy/zeta transforms; the shared optical potential behind the probe's entropy minimum and the photon sphere; a specified O(3) sigma probe with an integrated one-loop beta function and evaluated Perelman functional; and a nonstationary detector trajectory with its derivative expansion.

This is a source-linked working calculation, not independent peer review. Novelty is unassessed. No claim of solving quantum gravity, a Millennium problem, or a universal equivalence of all flows is made.
